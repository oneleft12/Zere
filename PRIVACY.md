# Политика конфиденциальности ZERE

**Коротко: ZERE работает на вашем компьютере и не отправляет данные
разработчику. Телеметрии нет.**

## Какие данные хранятся и где

| Данные | Файл | Назначение |
|---|---|---|
| Память (факты о вас) | `zere.db` (SQLite, таблица `Memories`) | чтобы ассистент помнил контекст |
| История диалогов | `zere.db` (таблица `Conversations`) | экран «История», контекст ответа |
| Настройки | `config/config.json`, `config/plugins.json` | модель, голос, личность |
| Ключ облачной модели (если введён) | `config/ai.json` | доступ к вашему API; права 0600 / `icacls` |
| Ключ роутера Jev (если включён) | `config/router.json` | доступ к OpenRouter |
| Токен локальной панели | `config/panel.token` | защита `http://127.0.0.1` |
| Журналы | `logs/*.log` | диагностика; ключи в логах маскируются |
| Записи голоса | `voice/`, `data/` | распознавание речи, референс клонирования |
| Снимки экрана для рисования | временные файлы | передаются в Paint/Krita, не уходят в сеть |

Всё это лежит в каталоге установки/репозитория на вашем диске.

## Что уходит в сеть

ZERE не имеет собственного сервера и не отправляет статистику. Сеть
используется только в сценариях, которые вы включили:

- **Локальная модель (Ollama)** — запросы идут на `127.0.0.1:11434`, никуда
  не покидают компьютер.
- **Облачная модель** — если вы ввели свой ключ, текст запроса уходит
  выбранному вами провайдеру (OpenAI/DeepSeek/OpenRouter/Groq и т. п.) по
  вашему выбору. Условия обработки — у этого провайдера.
- **Обновление из GitHub** — `git fetch` к репозиторию проекта; передаётся
  только служебная информация git.
- **MCP-плагины** — браузер и заметки работают локально; если сервер MCP
  обращается к сайту, это происходит по вашей команде.
- **Загрузка моделей** — GigaAM/Silero скачиваются с апстрима при установке
  или первом запуске.

Никакой аналитики, crash-репортинга и «умных» пингов нет.

## Голос и биометрия

Записи микрофона нужны для распознавания команд и (опционально) клонирования
голоса. Они хранятся локально. В git-истории проекта есть несколько старых
тестовых аудиофайлов — новые записи в репозиторий не попадают (`.gitignore`).

## Удаление данных

- История: экран «История» → «Очистить» (или команда «очисти историю»).
- Память: «очисти память».
- Ключ: панель → «Подключение ИИ» → «Удалить ключ».
- Всё сразу: удалите каталог ZERE (или используйте деинсталлятор с очисткой
  данных). `config/`, `zere.db`, `logs/`, `voice/`, `data/` — пользовательские
  данные, обновление их не перезаписывает.

## Дети

Продукт не предназначен для детей и не собирает данные о них.
