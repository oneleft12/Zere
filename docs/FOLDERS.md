# Поиск папок и открытие в проводнике

Команды «найди папку …» и «открой папку …» ищут не только на рабочем столе,
а по стандартным папкам пользователя, его профилю и локальным дискам.
Найденную папку можно открыть в проводнике — из чата или кнопкой на экране
панели «Папки».

## Команды

| Фраза | Что делает |
|---|---|
| `найди папку проекты` | Показывает совпадения с путями |
| `найди проекты` | Сначала ищет приложение, если его нет — папку |
| `где папка загрузки` | То же (алиасы стандартных папок) |
| `открой папку проекты` | Ищет и открывает однозначное совпадение |
| `открой папку загрузки` | Открывает стандартную папку |
| `открой папку` / `открой её` | Открывает последнюю найденную/открытую папку |
| `открой папку 2` | Открывает второй результат прошлой выдачи |
| `открой C:\Projects` | Открывает существующий путь напрямую |

Если запрос дал несколько равных совпадений, ZERE не угадывает: показывает
нумерованный список и ждёт «открой папку 1» (или более точного имени).
Это защита от открытия чужого проекта с похожим названием.

## Как ищется

`FolderSearchService` (`zere/tools/files/folder_search.py`):

- **Область**: Desktop, Documents, Downloads, Pictures, Music, Videos,
  OneDrive (вариант OneDrive важнее обычного), профиль пользователя и
  локальные диски Windows (`GetDriveTypeW == DRIVE_FIXED`). Съёмные и
  сетевые диски не обходятся.
- **Обход**: BFS, сначала мелкие уровни. Пределы по умолчанию — глубина 6,
  20 000 каталогов, 2 секунды (явное «Обновить» в панели — до 6 секунд).
  Индекс живёт 60 секунд; панель может сбросить его параметром `refresh=1`.
- **Пропуски**: `AppData`, `Windows`, `Program Files`, `ProgramData`,
  `$Recycle.Bin`, `System Volume Information`, `node_modules`, `.git`,
  `venv`, `__pycache__`, скрытые каталоги, symlink/junction (переходные
  точки). Поэтому обход не зацикливается и не тонет в служебных файлах.
- **Ранжирование**: точное имя (1000) → начало имени (850) → все слова
  (780) → часть имени (700/640) → опечатка (≈400) → прямой путь (1000).
  При равенстве — меньшая глубина, короткое имя, путь.
- **Нормализация**: регистр и «ё/е» не важны; латиница транслитерируется
  («proekty» → «Проекты»); типовые русские
  названия находят английские папки («проекты» → `Projects`).
- **Алиасы**: «рабочий стол», «загрузки», «документы», «картинки», «музыка»,
  «видео», «домашняя папка», «профиль», `desktop`, `downloads`, `home`.
- **Честность**: если обход упёрся в предел, ответ помечается
  `truncated: true` и в чате/панели видно, что выдача неполная.

## Открытие

`FolderOpener` (`zere/tools/files/folder_opener.py`) открывает только
существующий каталог:

- Windows — `os.startfile(path)` (проводник);
- macOS — `open`;
- Linux — `xdg-open`.

Путь передаётся аргументом, без `shell=True`; произвольный файл открыть
нельзя — проверяется `is_dir()`. Ошибка ОС возвращается текстом, а не
исключением.

## API панели (только Python-редакция)

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/folders?q=&limit=&refresh=` | Поиск; пустой `q` — стандартные папки |
| `POST` | `/api/folders/open` `{path}` | Открыть существующую папку |

Ответ поиска: `{items, total, truncated, durationMs, indexed}`;
элемент — `{name, path, parent, modified, score, reason}`.
Ответ открытия: `{opened, path, message}`.

Контракт — `docs/api/openapi.yaml`. C#-панель этих маршрутов не имеет:
экран «Папки» прячется по 404 (`foldersSupport()` в `panel/src/api.ts`).

## Экран «Папки»

`panel/src/screens/folders.ts`: поиск с задержкой 300 мс, таблица
«Папка · Путь · Изменена · Совпадение», кнопка «Открыть» у каждой строки,
кнопка «Обновить» (сбрасывает кэш индекса). Пустой запрос показывает
стандартные папки.

## Безопасность

- Поиск только читает имена каталогов; содержимое файлов не читается.
- Запись и удаление по-прежнему ограничены рабочим столом: расширение
  области поиска не расширяет область изменения.
- Открытие — действие пользователя (чат или кнопка панели), не автоматика
  по найденному пути.
- Неоднозначный запрос не открывает первую папку «наугад».
