# Дизайн-система панели ZERE

**Дата:** 2026-10-11
**Область:** `panel/` — web-панель (Vite + vanilla TypeScript), общая для Python- и C#-редакций.
**Режим поверхности:** **Operate** — пользователь выполняет задачи: смотрит состояние служб, говорит с ассистентом, правит настройки, читает логи. Выразительность здесь подчинена читаемости и скорости.

---

## 1. Мир

Диспетчерская одного ассистента. База — чернильная (приборная), свет идёт из глубины: циан ассистента и фиолет второго контура данных. Тёмная тема — основная (вечер, свет в комнате выключен), светлая — инверсия слоёв, а не другая вселенная.

Правила, которые держат мир:

- **Слои вместо рамок.** Глубина строится тремя поверхностями (`--surface`, `--surface-2`, `--surface-3`) и тонкой линией `--border`; тень только там, где элемент действительно над плоскостью.
- **Свет — это состояние.** Циан означает «здесь живёт ассистент»: активный пункт навигации, орб, значение в фокусе. Фиолет (`--accent-2`) — второй контур: служебные числа и метки. Больше цветов нет.
- **Никаких эмодзи вместо иконок.** Весь интерфейс использует набор `panel/src/icons.ts`: сетка 24×24, поле 3px, штрих 1.6, `currentColor`.

## 2. Токены

Все значения — `panel/src/styles/tokens.css`. Токены не дублируются по компонентам: экран, которому нужен цвет или отступ, берёт переменную.

| Группа | Токены | Назначение |
|---|---|---|
| Слои | `--bg`, `--bg-2`, `--surface`, `--surface-2`, `--surface-3`, `--surface-glass` | фон, карточка, наведение, вложенный блок |
| Свет | `--accent`, `--accent-2`, `--accent-contrast` | ассистент, данные, текст на акценте |
| Текст | `--text`, `--text-dim`, `--text-faint` | основной, пояснения, служебные метки |
| Состояния | `--ok`, `--warn`, `--danger` + `*-soft` | служба работает, предупреждение, сбой |
| Ритм | `--space-1…7` | шаг 4 → 44px |
| Формы | `--radius-xs…full` | 6 → 999px |
| Тени | `--elev-1…3` | плоскость, всплытие, оверлей |
| Каркас | `--sidebar-w`, `--sidebar-w-rail`, `--header-h`, `--status-h`, `--content-max` | сетка оболочки |
| Движение | `--dur-1…4`, `--ease-out`, `--ease-in-out` | 120/200/320/560 мс |

**Типографика.** `--font-ui` и `--font-display` — оптические начертания Windows (`Segoe UI Variable`), `--font-mono` — Cascadia. Веб-шрифт не подключается: панель обязана работать офлайн, а подмена «похожим» шрифтом ломает метрику. Шкала: 10.5 / 11.5 / 12.5 / 13.5 / 15 / 18 / 24 / 30px. Числа — `font-variant-numeric: tabular-nums` всегда, включая метрики дашборда: цифры не должны «плясать» при обновлении.

## 3. Движение

Тезис движения — три роли, и ни одной сверх:

1. **Фокусный момент — орб ассистента.** Единственная авторская фигура продукта: кольца орба читаются как состояние, а не как украшение.

   | Состояние | Что видно | Когда |
   |---|---|---|
   | `idle` | медленное дыхание сердцевины | ассистент готов |
   | `listening` | расходящееся кольцо | голосовой режим ждёт слово-триггер или команду |
   | `thinking` | вращающийся сегмент контура | запрос ушёл, ответ ещё не пришёл |
   | `speaking` | волна за волной | идёт поток ответа или озвучка |
   | `error` / `offline` | цвет без движения | ИИ не настроен, нет связи с панелью |

   Орб живёт в статус-строке и повторяется на экране «Голос» (`orb--lg`). Экраны объявляют состояние событием `zere-assistant-state` (`panel/src/events.ts`), оболочка показывает.

2. **Непрерывность.** Переход между экранами — вход 320 мс снизу (`zere-route-in`); активный пункт навигации помечает переезжающий индикатор (`--rail-y`), а не мигающая подсветка; сворачивание сайдбара в рейку — 320 мс; раскрытие панели команд чата анимируется по реальной высоте (`motion.ts: slideToggle`).

3. **Обратная связь.** Кнопка проседает на 1px при нажатии, toggle перевозит ползунок, slider заливает трек до значения, тост уходит быстрее, чем приходит, метрики досчитываются (`countUp`), изменившаяся строка подсвечивается (`flash`), списки приходят волной (`staggerChildren`, не больше 12 элементов и 240 мс общей задержки).

**Бюджет.** Дорогие эффекты ограничены: `backdrop-filter` — шапка, подвал, модалка, палитра; циклы (орб, скелетон, пульс состояния) останавливаются при `document.hidden` через `html[data-doc-hidden="1"]`.

**Уменьшение движения.** `prefers-reduced-motion` убирает перемещение и циклы, но сохраняет появление, цвет и смену состояния: подтверждение действия должно остаться. Флаг дублируется в `html[data-reduced-motion]` (`motion.ts: initMotionGuards`), а `countUp`/`slideToggle`/`staggerChildren` проверяют настройку сами.

## 4. Компоненты

`panel/src/ui.ts` — единственный источник элементов; экраны не собирают разметку вручную. Базовые: `button` (+`withIcon`, `iconButton`), `card`, `statusPill`, `badge`, `metric`/`metricAnimated`, `field`, `textInput`, `select`, `toggle`, `slider`, `table`, `emptyState`, `skeleton`, `loadingRow`, `modal`/`confirmDialog`, `toast`, `pageHeader`, `keyValue`, `codeBlock`, `orb`, `sectionTitle`.

Отдельно: **командная палитра** (`panel/src/palette.ts`) — Ctrl+K, экраны, действия панели и команды ZERE одним полем.

## 5. Доступность и проверка

- Контраст: текст ≥4.5:1, крупный ≥3:1 — в обеих темах (акцент светлой темы затемнён до `#00707f` именно поэтому).
- Фокус: единое кольцо `outline: 2px solid var(--accent)` на всём интерактиве; у невидимого чекбокса toggle кольцо рисуется на треке.
- Цели нажатия ≥24px; иконки без подписи получают `aria-label`.
- Хром браузера оформлен: выделение, каретка, скроллбары, `scrollbar-color`, табличные цифры.
- Хиро-метрики, капслок-надписи, эмодзи-иконки и цветные `border-left` в карточках не используются: это признаки шаблона, а не решения.

Проверка перед коммитом (обе команды — из `panel/`):

```bash
npm run build                 # tsc + vite → panel/dist (коммитится)
npx playwright test           # 37 e2e: экраны, чат, голосовое, команды, ИИ, обновления, голос
node e2e/audit.cjs            # расширенный аудит: XSS, обрыв связи, 390×844, i18n
```

`panel/dist` общий для двух редакций: после правок панели его нужно пересобрать и закоммитить, иначе C#- и Python-панели отдадут старый интерфейс.

## 6. Правила правки

1. Классы, за которые держатся e2e (`e2e/*.spec.ts`): `.card`, `.msg`/`.msg--user`/`.msg--assistant`, `.loading-row`, `.nav-item[title]`, `.shell__status`, `.page-header__title`, `.chat__commands*`, `.chat__mic`, `.chat__mode`, `.cmd*`, `.form-error`, `.status-pill__value`, `.toast`, `.table`. Переименование = падающий сценарий приёмки.
2. Тексты интерфейса не хардкодятся: строка идёт через `t()`, перевод — в `panel/src/i18n/<экран>.ts` (ключ — точная русская строка).
3. Экраны не расставляют внешние отступы: вертикальный ритм задаёт `.shell__content` (flex + `gap`).
4. Новое движение добавляется только с ответом на вопрос «что это объясняет». Декоративные циклы не заводятся.
