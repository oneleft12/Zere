## ПЛАН РАЗВИТИЯ

---

### 🔴 Приоритет 1 — Стабильность и качество

#### 1.1 Обработка ошибок и восстановление
- [x] Auto-reconnect Whisper при ошибке загрузки модели
- [x] Auto-reconnect Piper при ошибке ( processo crash)
- [x] Fallback: если Whisper не отвечает → текстовый ввод
- [x] Fallback: если Piper не отвечает → текстовый вывод
- [x] Таймауты на все внешние вызовы (Whisper, Piper, Ollama)
- [x] Логирование ошибок в файл (logs/errors.log)

#### 1.2 Улучшение распознавания речи
- [x] Фильтрация артефактов Whisper (пустые строки, повторы)
- [x] Кэширование Whisper модели в памяти (быстрый restart)
- [x] Поддержка multiple whisper моделей (auto-select по языку) — реализовано: размер из конфига (`whisperModelSize`) + auto-select medium/base по наличию скачанной модели; авто-выбор *по языку* отложен (проект фиксирован на ru)
- [ ] Визуальная индикация уровня микрофона в реальном времени *(отложена: требует живого аудиоввода, проверять на Windows)*

#### 1.3 Кэширование и производительность
- [x] Кэш Ollama-ответов (по хешу запроса)
- [x] Предзагрузка Whisper при старте (не ждать первого вызова)
- [ ] Фоновая загрузка моделей Piper (par voice) — *не применимо в текущей архитектуре: piper — отдельный процесс на каждый вызов синтеза; пересмотреть при переходе на долгоживущий piper-процесс*
- [x] Очистка voice/input/ при каждом запуске
