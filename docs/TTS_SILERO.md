# TTS на Silero v5 (русский голос)

**Код:** `zere/voice/silero/silero_manager.py`, `zere/voice/silero/silero_service.py`
(Python-редакция), `ZERE.Voice/Silero/SileroTtsService.cs` (C#-редакция), сайдкар
`tools/zere_silero_server.py`.
**Тесты:** `tests/test_silero.py` (23) + контрактные `/api/voice` в
`tests/test_panel_api.py`.
**Движок выбирается:** `ttsEngine` в `config/config.json` — `chattts` | `silero`
(Python-редакция; в C# есть ещё `pocket` — клонирование голоса).

---

## 1. Зачем второй движок

ChatTTS официально поддерживает **китайский и английский**. На кириллице он
фонетически ломается: нормализатор пишет `found invalid characters`, ударения
ставятся случайно — русская речь звучит неразборчиво. Это ограничение
**движка**, а не настройки.

Silero `v5_5_ru` — русская модель с автоматическими **ударениями** и
**омографами** (v5_4_ru и новее — ещё и с вопросительной интонацией). Замер на
рабочей машине (CPU, 6 потоков, фраза 4.7 с):

| Движок | Синтез фразы 4.7 с | Первый запуск | Модель |
|---|---|---|---|
| ChatTTS | 4–9 с | ~2–3 ГБ (torch + веса) | ~1.2 ГБ ассетов HF |
| **Silero v5_5_ru** | **0.27–1.7 с** | 145 МБ (модель) + torch | **145 МБ** |

RTF у Silero — примерно 0.06–0.36, у ChatTTS — 1–2. То есть на CPU Silero в
10–20 раз быстрее и звучит по-русски естественно.

**Лицензия весов** — `CC-NC-BY` (как и у ChatTTS): для личного использования
годится, для коммерческого релиза это блокер (`docs/COMMERCIAL_RELEASE_PLAN.md`).
MIT-варианты Silero (`v5_cis_base*`) требуют вручную расставлять ударения
(`к+ошка`) — для голосового ассистента это неприемлемо.

## 2. Как включить

1. `config/config.json` → `"ttsEngine": "silero"`, **или** панель → «Голос» →
   «TTS-движок» → `silero — русский голос, с ударениями`.
2. Перезапустить ZERE (смена движка применяется на старте, как написано на
   экране).
3. Первый синтез скачает модель `v5_5_ru.pt` (145 МБ) в
   `ZERE.Voice/Silero/` — дальше она используется из кэша, интернет не нужен.

Проверка: панель → «Голос» → «Тест» → «Озвучить» (503 с причиной, если
окружение не готово). Для Python-редакции нужен `torch` — он уже приходит с
ChatTTS-стеком; для C#-редакции нужен `tools/uv.exe` (как и для ChatTTS).

---

## 3. Голоса

У Silero голоса **именованные** (в отличие от ChatTTS, где «профиль» — это
зерно эмбеддинга):

`baya` (дефолт), `xenia`, `kseniya` — женские; `aidar`, `eugene` — мужские.

| Стиль личности | Голос | Где задано |
|---|---|---|
| Friendly | `baya` | `VoiceManager._silero_voices` (Python) / `_sileroVoices` (C#) |
| Formal | `xenia` | там же |
| Sarcastic | `aidar` | там же |
| Professional | `eugene` | там же |
| Casual | `kseniya` | там же |

Неизвестное имя голоса (например, профиль ChatTTS `zere-standard`, оставшийся в
конфиге) не роняет движок: менеджер подменяет его дефолтным `baya`.

## 4. Ограничения

- **Темп речи не настраивается**: у Silero v5 нет параметра скорости.
  `speechSpeed` принимается ради общего контракта и игнорируется; панель честно
  показывает `скорость речи: фиксирована` (`capabilities.speechSpeedConfig=false`).
- **Клонирование голоса** — только PocketTTS (C#-редакция).
- **Русский — основной язык модели.** Английский/китайский по-прежнему лучше
  звучат у ChatTTS: движок выбирается ключом `ttsEngine`, оба остаются доступны.
- **Чужое предупреждение из модели гасится.** `v5_5_ru.pt` — это
  `torch.package`-архив, и его `multi_acc_v3_package.py:286` собирает регулярку
  через `'\^'`. Python 3.12+ компилирует этот файл при загрузке модели и печатал
  в консоль ZERE:

  ```
  <torch_package_0>.multi_acc_v3_package.py:286: SyntaxWarning: "\^" is an
  invalid escape sequence. Such sequences will not work in the future.
  ```

  Правкой кода это не убрать: файл лежит внутри 145-МБ модели, которая качается
  заново при удалении. Поэтому `SileroManager.load_model()` гасит предупреждение
  **точечно** — по тексту (`FOREIGN_SYNTAX_WARNING`) и только на время загрузки:
  остальные предупреждения чужого кода по-прежнему видны в консоли.

## 5. Ленивая загрузка (почему старт ZERE не платит за модель)

| Слой | Что делает `Initialize()` | Что происходит при первом синтезе |
|---|---|---|
| Python (`SileroTtsService.initialize`) | `importlib.util.find_spec` по `torch`/`soundfile` (без импорта) | `SileroManager.load_model`: скачивает `v5_5_ru.pt` (если нет), `torch.package.PackageImporter(...).load_pickle("tts_models", "model")`, `model.to(cpu)`, `torch.set_num_threads(≤8)` |
| C# (`SileroTtsService.Initialize`) | два `File.Exists` (`tools/uv.exe`, `tools/zere_silero_server.py`) | `EnsureServerAsync` поднимает сайдкар через uv, ждёт `/health` = `ready` (таймаут 10 минут — скачивание модели и подъём torch) |

Перепроверка доступности дешёвая (`RefreshAvailability()`), поэтому `torch`,
установленный при работающем ZERE, начинает работать без перезапуска. Как и у
ChatTTS, доступность поднимается **всегда** — даже при `voiceEnabled=false`,
иначе панель не могла бы протестировать синтез
(`zere/voice/voice_bootstrap.py`).

## 6. Сайдкар (C#-редакция)

```
tools/uv.exe run --python 3.12 --with torch --with soundfile \
    python tools/zere_silero_server.py --port 8473 --voice baya
```

`--python 3.12` — проверенная версия стека; torch берётся из того же кэша uv,
что и для ChatTTS. Эндпоинты:

| Метод | Путь | Ответ |
|---|---|---|
| GET | `/health` | `{"status": "loading"\|"ready"\|"error", "detail": str, "sample_rate": 24000, "voice": str, "voices": [...]}` |
| GET | `/voices` | `{"voices": [...]}` |
| POST | `/tts` | тело `{"text": "...", "voice": "baya", "silence": 0.2}` → `application/octet-stream` PCM **s16le** моно 24 кГц, заголовок `X-Sample-Rate` |

Модель грузится в фоне при старте сайдкара (поэтому `/health` успевает сказать
`loading`), а файл модели скачивается при первой загрузке. C#-клиент режет
текст на предложения (`SpeechText`), заворачивает PCM в WAV и отдаёт в обычный
тракт: DSP-обработка под частоту устройства + воспроизведение.

## 7. Что проверяют тесты

`tests/test_silero.py` (без torch/numpy/soundfile — фейки через `sys.modules`):

- доступность: нет `torch` → `(False, "нет модулей: torch …")`, есть → причина
  упоминает скачивание модели;
- ленивость: `initialize()` не грузит модель, `load_model()` вызывается один раз
  на процесс, файл модели качается только когда его нет;
- битый файл модели → `SileroUnavailable` с подсказкой удалить файл;
- чужой `SyntaxWarning` из кода внутри модели не печатается, а предупреждения с
  другим текстом и другого класса остаются видимыми (регрессия «заглушили всё
  вместо точечного фильтра»);
- голоса: «санитайзинг» чужого профиля и список именованных голосов;
- синтез: WAV на 24 кГц, разбивка на предложения, тишина `sentenceSilence`;
- контракт сервиса: чистка текста, фолбэк в текст без движка, честная причина
  недоступности (регрессия «недоступен: доступен»), `supports_speech_speed=false`;
- маршрутизация `VoiceManager`: `ttsEngine=silero` → Silero и голос стиля,
  `chattts`/`pocket` → ChatTTS;
- контракт сайдкара: импорт без torch, PCM s16le, `/health`, код возврата 2 на
  неизвестную команду.
