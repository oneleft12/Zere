# TTS на Silero v5 (русский голос)

**Код:** `zere/voice/silero/silero_manager.py`, `zere/voice/silero/silero_service.py`
(Python-редакция), `ZERE.Voice/Silero/SileroTtsService.cs` (C#-редакция), сайдкар
`tools/zere_silero_server.py`.
**Тесты:** `tests/test_silero.py` (38: ленивая загрузка, голоса, маршрутизация,
нормализация текста, сайдкар) + контрактные `/api/voice` в
`tests/test_panel_api.py`.
**Движок:** `ttsEngine` в `config/config.json` — `silero` (по умолчанию).
В C#-редакции есть ещё `pocket` — клонирование голоса; ChatTTS удалён в 1.9.0.

---

## 1. Почему Silero

До 1.9.0 в проекте было два TTS-движка, и ChatTTS официально поддерживал
только **китайский и английский**: на кириллице он фонетически ломался
(нормализатор писал `found invalid characters`, ударения ставились случайно),
а весил ~2–3 ГБ с torch. Поэтому ChatTTS удалён, а единственным движком стал
Silero — русская модель, которая и так использовалась для русской речи.

Silero `v5_5_ru` — русская модель с автоматическими **ударениями** и
**омографами** (v5_4_ru и новее — ещё и с вопросительной интонацией). Замер на
рабочей машине (CPU, 6 потоков, фраза 4.7 с): **0.27–1.7 с** синтеза;
RTF ≈ 0.06–0.36. Модель — 145 МБ, скачивается при первом синтезе.

**Лицензия весов** — `CC-NC-BY`: для личного использования
годится, для коммерческого релиза это блокер (`docs/COMMERCIAL_RELEASE_PLAN.md`).
MIT-варианты Silero (`v5_cis_base*`) требуют вручную расставлять ударения
(`к+ошка`) — для голосового ассистента это неприемлемо.

## 2. Как включить

1. В `config/config.json` уже стоит `"ttsEngine": "silero"`; в панели
   («Голос» → «TTS-движок») остаются `silero` и `pocket` (C#).
2. Первый синтез скачает модель `v5_5_ru.pt` (145 МБ) в
   `ZERE.Voice/Silero/` — дальше она используется из кэша, интернет не нужен.
3. `torch` ставится отдельным окружением: Python-редакция поднимает его через
   `zere/voice/silero`, C#-редакция — через `tools/uv.exe`.

Проверка: панель → «Голос» → «Тест» → «Озвучить» (503 с причиной, если
окружение не готово).

---

## 3. Голоса

У Silero голоса **именованные**:

`baya` (дефолт), `xenia`, `kseniya` — женские; `aidar`, `eugene` — мужские.

| Стиль личности | Голос | Где задано |
|---|---|---|
| Friendly | `baya` | `VoiceManager._silero_voices` (Python) / `_sileroVoices` (C#) |
| Formal | `xenia` | там же |
| Sarcastic | `aidar` | там же |
| Professional | `eugene` | там же |
| Casual | `kseniya` | там же |

Неизвестное имя голоса (например, старое `zere-standard`, оставшееся в
конфиге) не роняет движок: менеджер подменяет его дефолтным `baya`.

---

## 4. Ограничения

- **Темп речи не настраивается**: у Silero v5 нет параметра скорости.
  `speechSpeed` принимается ради общего контракта и игнорируется; панель честно
  показывает `скорость речи: фиксирована` (`capabilities.speechSpeedConfig=false`).
- **Клонирование голоса** — только PocketTTS (C#-редакция).
- **Только русская речь.** Английские слова и цифры модель сама не читает
  (см. §5): их раскрывает нормализация — латиница практической транскрипцией и
  числа прописью. При `language=en` ответ всё равно озвучивается русской
  моделью с транскрипцией латиницы — второго TTS-движка больше нет.
- **Чужое предупреждение из модели гасится.** `v5_5_ru.pt` — это
  `torch.package`-архив, и его `multi_acc_v3_package.py:286` собирает регулярку
  через `'\^'`. Python 3.12+ компилирует этот файл при загрузке модели и печатал
  в консоль ZERE:

  ```
  <torch_package_0>.multi_acc_v3_package.py:286: SyntaxWarning: "\^" is an
  invalid escape sequence. Such sequences will not work in the future.
  ```

  Правкой кода это не убрать: файл лежит внутри 145-МБ модели, которая качается
  заново при удалении. Поэтому `SileroManager.load_model()` гасит предупреждение
  **точечно** — по тексту (`FOREIGN_SYNTAX_WARNING`) и только на время загрузки:
  остальные предупреждения чужого кода по-прежнему видны в консоли.

## 5. Цифры, даты и английские слова (нормализация текста)

**Код:** `zere/voice/silero/silero_text.py` (раскрытие текста),
`zere/voice/silero/russian_numbers.py` (числа прописью),
`zere/voice/silero/silero_manager.py` → `waveform()` (точка входа).

### Почему это вообще понадобилось

У русской модели узкий **набор символов**, а всё незнакомое `apply_tts`
выбрасывает **молча** — ошибки нет, просто часть фразы исчезает из речи:

```
model.symbols = "_~|!+,-.:;?абвгдежзийклмнопрстуфхцчшщъыьэюяё–… "
```

В наборе нет ни цифр, ни латинских букв, ни `%`, `№`, `&`, `@`, ни длинного
тире `—`. Замер по синтезу самой модели (расшифровка faster-whisper, голос
`baya`, 24 кГц) до правки:

| Что просили произнести | Что слышно |
|---|---|
| «В 2026 году» | «В году» |
| «Цена 1500 рублей» | «Цена рублей» |
| «Открой GitHub» | «Открой» |
| «GitHub» (реплика целиком) | `ValueError`: после чистки не осталось символов |
| «Цена 3.5 рублей» | резалось ещё и на две реплики: «Цена 3.» + «5 рублей.» |

### Что делает нормализация

Порядок проходов (он важен, «5 GB» — это число с единицей, а не число и
латинское слово):

1. **Единицы, проценты, валюты** — `5 GB`, `65 °C`, `5%`, `120000 ₽`, `3,5 ГБ`
   → «пять гигабайтов», «шестьдесят пять градусов цельсия», «пять процентов»,
   «сто двадцать тысяч рублей», «три целых пять десятых гигабайта».
2. **Латиница** — словарь частых слов и терминов + правила практической
   транскрипции: `GitHub` → «Гитхаб», `Discord` → «Дискорд», `Python` →
   «Питон», `Hello, world!` → «хеллоу, уорлд!». Сокращения читаются по буквам
   (`CS2` → «си эс два», `RTX` → «ар ти экс»), слово с цифрой — буквы плюс
   число (`mp3` → «эм пи три», `v5` → «ви пять»).
3. **Числовое и символы** — числа, дроби, даты, время, годы, порядковые,
   `%`, `№`, `&`, `@`, `×`, `=`, тире:
   - «В 2026 году» → «В две тысячи двадцать шестом году» (год — порядковое
     числительное, падеж берётся от предлога: «с 2020 по 2024» → «с две тысячи
     двадцатого по две тысячи двадцать четвёртый»);
   - «12.05.2026» → «двенадцатое мая две тысячи двадцать шестого года»;
   - «13:45» → «тринадцать сорок пять»;
   - «3,5» → «три целых пять десятых», «1/2» → «одна вторая»;
   - «5-й» → «пятый», «65 °C» → «шестьдесят пять градусов цельсия»;
   - «GitHub.Com» → «Гитхаб ком», эмодзи и кавычки вырезаются.

Числа считает свой модуль (`russian_numbers.py`), а не `num2words`: не нужна
лишняя зависимость ни в ZERE, ни в сайдкаре C#-редакции, зато нужны
порядковые («две тысячи двадцать шестой год»), согласование («один процент»,
«два процента», «пять процентов») и падежи для единиц.

**Почему транскрипция, а не английская модель Silero.** Вторая модель — это
ещё ~150 МБ и переключение графа на каждой фразе, а английские вставки в
русской речи короткие («открой GitHub», «iPhone 15»). Словарь закрывает
частые термины, правила — остальное; длинный английский текст по-прежнему
это остаётся ограничением единственного движка.

### Проверка после правки (та же методика — ASR по синтезу модели)

| Просили | Расшифровка Whisper |
|---|---|
| «Открой GitHub и Discord» | «Открой GitHub и Discord.» |
| «Цена 1500 рублей» | «Цена 1500 рублей.» |
| «В 2026 году 3.5 ГБ и 87%» | «В 2026 году 3,5 ГБ и 87%.» |
| «Встреча 12.05.2026 в 13:45» | «Встреча 12 мая 2026 года в 13.45.» |
| «iPhone 15 и GitHub» | «iPhone 15 и GitHub.» |

Нормализация применяется в `SileroManager.waveform()`, то есть и в
Python-редакции, и в C#-редакции (та синтезирует через сайдкар, а сайдкар
зовёт тот же менеджер). Отдельная правка C# — `SpeechText.SplitSentences`:
точка между цифрами больше не считается концом предложения (паритет с
`zere/voice/speech_text.py`), иначе «3.5» уезжало в сайдкар двумя репликами.

## 6. Ленивая загрузка (почему старт ZERE не платит за модель)

| Слой | Что делает `Initialize()` | Что происходит при первом синтезе |
|---|---|---|
| Python (`SileroTtsService.initialize`) | `importlib.util.find_spec` по `torch`/`soundfile` (без импорта) | `SileroManager.load_model`: скачивает `v5_5_ru.pt` (если нет), `torch.package.PackageImporter(...).load_pickle("tts_models", "model")`, `model.to(cpu)`, `torch.set_num_threads(≤8)` |
| C# (`SileroTtsService.Initialize`) | два `File.Exists` (`tools/uv.exe`, `tools/zere_silero_server.py`) | `EnsureServerAsync` поднимает сайдкар через uv, ждёт `/health` = `ready` (таймаут 10 минут — скачивание модели и подъём torch) |

Перепроверка доступности дешёвая (`RefreshAvailability()`), поэтому `torch`,
установленный при работающем ZERE, начинает работать без перезапуска.
Доступность поднимается **всегда** — даже при `voiceEnabled=false`,
иначе панель не могла бы протестировать синтез
(`zere/voice/voice_bootstrap.py`).

## 7. Сайдкар (C#-редакция)

```
tools/uv.exe run --python 3.12 --with torch --with soundfile \
    python tools/zere_silero_server.py --port 8473 --voice baya
```

`--python 3.12` — проверенная версия стека; torch uv кладёт в свой кэш.
Эндпоинты:

| Метод | Путь | Ответ |
|---|---|---|
| GET | `/health` | `{"status": "loading"\|"ready"\|"error", "detail": str, "sample_rate": 24000, "voice": str, "voices": [...]}` |
| GET | `/voices` | `{"voices": [...]}` |
| POST | `/tts` | тело `{"text": "...", "voice": "baya", "silence": 0.2}` → `application/octet-stream` PCM **s16le** моно 24 кГц, заголовок `X-Sample-Rate` |

Модель грузится в фоне при старте сайдкара (поэтому `/health` успевает сказать
`loading`), а файл модели скачивается при первой загрузке. C#-клиент режет
текст на предложения (`SpeechText`), заворачивает PCM в WAV и отдаёт в обычный
тракт: DSP-обработка под частоту устройства + воспроизведение.

## 8. Что проверяют тесты

`tests/test_silero.py` (без torch/numpy/soundfile — фейки через `sys.modules`):

- доступность: нет `torch` → `(False, "нет модулей: torch …")`, есть → причина
  упоминает скачивание модели;
- ленивость: `initialize()` не грузит модель, `load_model()` вызывается один раз
  на процесс, файл модели качается только когда его нет;
- битый файл модели → `SileroUnavailable` с подсказкой удалить файл;
- чужой `SyntaxWarning` из кода внутри модели не печатается, а предупреждения с
  другим текстом и другого класса остаются видимыми (регрессия «заглушили всё
  вместо точечного фильтра»);
- голоса: «санитайзинг» чужого профиля и список именованных голосов;
- синтез: WAV на 24 кГц, разбивка на предложения, тишина `sentenceSilence`;
- контракт сервиса: чистка текста, фолбэк в текст без движка, честная причина
  недоступности (регрессия «недоступен: доступен»), `supports_speech_speed=false`;
- маршрутизация `VoiceManager`: любое значение `ttsEngine` ведёт в Silero
  (старые `chattts`/`pocket` из общего конфига не роняют старт);
- контракт сайдкара: импорт без torch, PCM s16le, `/health`, код возврата 2 на
  неизвестную команду;
- текст (§5): числа прописью (род, разряды, согласование, «минус»), годы и даты
  падежами, дроби, единицы и проценты, латиница словарём и правилами, сокращения
  по буквам, символы модели (`%`, `№`, `&`, `@`, `×`, тире), идемпотентность;
- **гарантия контракта**: после `normalize()` в тексте не остаётся ни одной
  латинской буквы и ни одной цифры — ровно то, что модель молча выбрасывает
  (регрессия «В 2026 году» звучит как «В году», «GitHub» исчезает);
- регрессия разбивки на предложения: «Цена 3.5 рублей. Спасибо.» — две реплики,
  а не три (точка между цифрами больше не конец предложения).
