# YouTube и музыка

«Включи музыку» — команда ZERE, которая открывает YouTube и **включает**
воспроизведение, а не просто показывает сайт. Работает в Python-редакции;
в C#-редакции команд пока нет.

## Команды

| Фраза | Что делает |
|---|---|
| `включи музыку` | YouTube → поиск «музыка» → первое видео → микс → Play |
| `включи джаз на ютубе` | то же для произвольного запроса |
| `включи на ютубе лофай` | то же, запрос после «на ютубе» |
| `включи музыку рок` | запрос после слова «музыку» |
| `открой ютуб`, `ютуб` | открыть YouTube без воспроизведения |
| `пауза`, `выключи музыку` | пауза |
| `продолжи`, `сними с паузы` | продолжить |
| `следующий трек`, `следующая песня` | следующий трек микса |
| `предыдущий трек` | предыдущий трек |
| `что играет` | название трека и состояние (играет/пауза) |

Английские варианты (`play music`, `open youtube`, `pause`, `next track`,
`what is playing`) тоже понимаются.

Команды стоят в конвейере **до** `WindowsHandler`: иначе «открой ютуб»
уходило бы в поиск приложений и заканчивалось ответом «Не удалось найти
приложение «ютуб»».

## Как включается музыка

Браузеры блокируют автозапуск видео со звуком без действия пользователя,
поэтому открыть ссылку недостаточно. ZERE использует уже существующий
плагин браузера **Playwright MCP** (`config/mcp.json`, по умолчанию Edge):

1. `browser_run_code_unsafe` открывает поиск YouTube;
2. берётся первая ссылка `a#video-title` (до 10 попыток — реклама и
   закреплённые блоки пропускаются);
3. видео открывается как **микс** (`watch?v=…&list=RD…&start_radio=1`),
   чтобы «следующий трек» работал и музыка не заканчивалась;
4. если плеер на паузе, кликается `.ytp-play-button` — это настоящий клик
   Playwright, браузер считает его действием пользователя и разрешает звук.

Весь Playwright-код фиксирован в `zere/tools/media/youtube_service.py`;
поисковый запрос подставляется через `JSON.stringify`, поэтому текст
пользователя не может превратиться в произвольный JS.

## Если плагин браузера выключен

`YouTubeService` честно откатывается на браузер по умолчанию
(`os.startfile`/`webbrowser`): открывает страницу поиска YouTube и пишет,
что автовоспроизведение недоступно. Управление (пауза, треки) в этом режиме
не работает — ZERE не управляет чужим браузером.

Включить автовоспроизведение:

```json
{
  "servers": {
    "playwright": {
      "enabled": true,
      "command": "npx",
      "args": ["-y", "@playwright/mcp@0.0.83"],
      "browser": "edge"
    }
  }
}
```

Файл — `config/mcp.json` (gitignored; образец — `config/mcp.example.json`).
Браузер меняется командой «браузер выбери chrome» или во вкладке «Плагины»
панели.

## Ограничения

- **Отдельный профиль.** Playwright MCP запускает Edge со своим профилем:
  вход в аккаунт YouTube, подписки и рекомендации пользователя там не
  действуют. Для «включи музыку» это не важно, для «моего плейлиста» —
  важно (пока не поддерживается).
- **Реклама.** Перед видео может быть рекламный ролик; клик Play
  пропускается, если плеер уже играет.
- **Управление живёт, пока жив браузер ZERE.** После перезапуска ZERE
  старый браузер может остаться, но новый MCP-сервер откроет свой — пауза
  попадёт в новую страницу. Если музыка играет в обычном браузере,
  управлять ею ZERE не может.
- **Не YouTube Music.** Используется обычный youtube.com: без входа
  доступны поиск, видео и миксы, но не личная библиотека YouTube Music.
- **Только Python-редакция.** В C#-редакции команды не зарегистрированы.

## Код

| Файл | Назначение |
|---|---|
| `zere/tools/media/youtube_command.py` | тип команды и константы действий |
| `zere/tools/media/youtube_command_router.py` | разбор русских/английских фраз (чистые функции) |
| `zere/tools/media/youtube_service.py` | открытие, поиск и Play, управление плеером, откат на браузер по умолчанию |
| `zere/core/handlers/media_handler.py` | обработчик конвейера |
| `zere/core/plugins/builtin/mcp/playwright_plugin.py` | публичный `run_code()` — драйвер `browser_run_code_unsafe` |
| `zere/core/services.py` | сборка: `YouTubeService` получает плагин браузера, `MediaHandler` — до `WindowsHandler` |

## Тесты

`tests/test_youtube_music.py` — разбор фраз (включая «не наши»: «включи
звук», «включи музыку громче»), ответы сервиса на успех/отказы/ошибки
драйвера, откат на браузер по умолчанию, обработчик и `run_code` плагина.
Сеть и браузер не нужны: драйвер и открытие ссылки подменяются фейками.

Живая проверка (Windows, Edge установлен, плагин включён):

```powershell
.venv\Scripts\python.exe -c "from zere.core.plugins.builtin.mcp.playwright_plugin import PlaywrightMcpPlugin; from zere.tools.media.youtube_service import YouTubeService; p=PlaywrightMcpPlugin(); p.initialize(); print(YouTubeService(driver=p).play_music('lofi'))"
```
