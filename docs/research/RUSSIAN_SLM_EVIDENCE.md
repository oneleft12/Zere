## MERA (русский бенчмарк) — что найдено

- **MERA**: 21 задача для русского языка, лидерборд <https://mera.a-ai.ru/en/text/leaderboard>, код <https://github.com/MERA-Evaluation/MERA>, статья <https://arxiv.org/abs/2401.04531>.
- **Llama-3.2-3B-Instruct**: итог MERA **0.324**, место 448; ruMMLU **0.419**; LCS 0.118; ruHumanEval 0.004/0.009/0.012 — <https://mera.a-ai.ru/en/text/submits/12022> (замер на 1×H100, vLLM — это не CPU).
- **Gemma-4-E4B-it**: мультимодальный борд MERA **0.467** (место 3), WEIRD 0.662, ruSLUn 0.304 — <https://mera.a-ai.ru/en/multi/submits/455>.
- **Независимый харнесс на датасетах MERA ruMMLU** (14 012 вопросов, RTX PRO 6000 Blackwell, не CPU): Gemma-4-12B fp8 **0.8103**, Gemma-4-E4B bf16 **0.7688**, Gemma-4-26B-A4B QAT-GGUF 0.7006 — <https://daniel.csylabs.com/en/2026-07-07-open-models-blackwell-nvfp4-en>.
- Для Phi-4-mini / Gemma 3 1B/4B / Granite / SmolLM3 / LFM2 / Ministral **сабмитов в MERA не найдено → НЕ ПОДТВЕРЖДЕНО**.

## Оговорки по методу

- Железо для замеров указано везде, где источник его называет. Youyeetoo X1S = Intel N5095, 4C/4T, 2.0/2.8 ГГц, DDR4-2933 (<https://shop.youyeetoo.com/blog/detail/introducing-the-x1s-drop-in-n5095-board-ends-n5105-shortage—zero-re-engineering-required>).
- Строки Jetson Orin Nano (Granite) и RTX PRO 6000 / A100 / H100 (Gemma 4, Llama 3.2 MERA) — **не CPU-only**, помечены явно.
- Ничего не додумано: где источника не было — стоит **НЕ ПОДТВЕРЖДЕНО**.
