# Русскоязычные SLM для локального запуска на CPU (4–16 ГБ RAM), релизы ≈01.2025–10.2026

Данные собраны 13.10.2026 через web_search + прямые запросы к huggingface.co/api/models, huggingface.co/<repo>/raw/main/README.md и https://ollama.com/<model>/tags (эндпоинт `/tags` отдаёт JSON — все теги ниже проверены фактическим запросом, не выдуманы).
Помечено `НЕ ПОДТВЕРЖДЕНО`, если факт отсутствует в источниках. Оценки скорости/ОЗУ — расчётные (живых замеров t/s в источниках нет) и помечены как «оценка».
1 ГБ = 10⁹ байт (как в файлах HF), 1 ГиБ = 2³⁰ байт.

## 3. Отдельные вопросы из задания

- **YandexGPT 5 Lite**: веса **открыты** (pretrain 21.02.2025, instruct 28.03.2025), лицензия `other` с именем `yandexgpt-5-lite-8b`, есть **официальный GGUF-репозиторий** и **официальная страница на ollama.com**. См. п.3 таблицы.
- **YandexGPT 5 Pro / 5.1 Pro**: открытых весов нет — используется в Алисе и Yandex Cloud (только API). `НЕ ПОДТВЕРЖДЕНО`, что Pro выкладывался в open weights; в HF-организации `yandex` моделей Pro нет.
- **YaFSDP**: это не модель, а открытый фреймворк шардированного параллелизма Яндекса — github.com/yandex/YaFSDP (Apache/MIT не проверял). Отношения к локальному запуску SLM не имеет.
- **GigaChat (Sber)**: веса **открыты** начиная с `GigaChat-20B-A3B-instruct` (13.12.2024) и далее — всё под **MIT**, с GGUF-репозиториями. Ключевое для слабых ПК — `GigaChat3-10B-A1.8B` / `GigaChat3.1-10B-A1.8B` (MoE, 1.8B активных).
- **MERA**: это **бенчмарк** (mera.a-ai.ru), а не семейство моделей. Отдельной релизной модели «MERA-Qwen» **не существует** (`НЕ ПОДТВЕРЖДЕНО`); на HF находятся только мелкие экспериментальные LoRA/SFT: `sofinvalery/mera-qwen3-4b-sft`, `sofinvalery/mera-qwen3-4b-rlvr`, серия `ikkiren/qwen-2.5-1.5b-instruct-ru-lora-...-mera-*` (апрель 2026, без лицензий и описаний).
- **«Ru-Llama»**: как оформленного семейства с открытыми весами не найдено (`НЕ ПОДТВЕРЖДЕНО`). Ближайшее по названию: `SAi404/ru_llama_3.2_3b`, `The-CoLab/llama3-7b-en-ru`, `uonlp/okapi-ru-llama` (2024). Настоящая линия «русской адаптации» — это **RuAdapt** (MSU-rcc / RefalMachine).
- **T-lite-instruct-0.1** (исходная, Т-Банк): HF-репозиторий `t-bank-ai/T-lite-instruct-0.1` **редиректит** на `AnatoliiPotapov/T-lite-instruct-0.1` (создан 16.07.2024, 8B, архитектура llama, 103 лайка). В карточке и в cardData HF **лицензия отсутствует** → лицензия `НЕ ПОДТВЕРЖДЕНО` (сторонние GGUF-репозитории `AlekseyElygin/...`, `QuantFactory/...` заявляют apache-2.0, но это утверждение загрузчиков). Контекст и tool calling в карточке не указаны → `НЕ ПОДТВЕРЖДЕНО`.
- **T-lite-it-1.0** (Qwen2.5, 10.12.2024): в карточке фронтматтер только `language: ru`, **лицензия не указана** → `НЕ ПОДТВЕРЖДЕНО`; tool calling **явно отсутствует** (карточка T-lite-it-2.1: «T-lite-it-1.0 … lacks tool-use support»). Официальная GGUF-версия — только `t-tech/T-lite-it-1.0-Q8_0-GGUF`.
- **Официальная библиотека Ollama**: русских LLM в ней **нет** — все найденные теги лежат в пользовательских/организационных namespace (`t-tech/...`, `yandex/...`, `ilyagusev/...`, `second_constantine/...` и др.). Из них только `t-tech/T-lite-it-2.1` и `yandex/YandexGPT-5-Lite-8B-instruct-GGUF` принадлежат самим разработчикам.
- **`A-vibe`** (упомянута как baseline в бенчмарк-таблице T-lite-it-2.1): в HF API модели с таким именем **не найдено** → `НЕ ПОДТВЕРЖДЕНО`.
- **Скорость на CPU**: замеров токенов/с на CPU в найденных источниках нет. Карточки дают только серверные метрики (H100/vLLM). Оценки в колонке «CPU-пригодность» — производные от числа параметров и активных параметров MoE, а не измеренный факт.
- **Saiga — последние версии**: `saiga_gemma3_12b` (20.04.2025) и `saiga_yandexgpt_8b` (04.03.2025). Новее в 2025–2026 у IlyaGusev по RU-инструктам нет (после апреля 2025 — только эксперименты по шахматам на Qwen3 и eagle/SAINEMO-варианты Saiga-Nemo).
- **Vikhr — последние версии**: линия `QVikhr-3-*` на Qwen3 (1.7B 29.05.2025, 4B 28.06.2025, 8B 05.08.2025) и `Vistral-24B-Instruct` (28.09.2025). В 2026 у Vikhrmodels новых текстовых LLM нет — только мультимодальный/аудио `Borealis` (ASR/audio, апр–дек 2025).
